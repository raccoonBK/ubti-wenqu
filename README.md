# UBTI · 先认清你是什么人，再预演你的大学生活

未央黑客松 WeYoung Hackathon 2026 · 赛道二「你好，我的大学」

> 别人都在做"扮演一个大一新生去聊天"的模拟器。我们不。
> 先用 UBTI 认出你是十六型里的哪一种，再把你写下的忐忑，预演成一幕幕会发生的大学日常。
> 你的期待和焦虑，变成你的作品。

## 它解决什么

新生真正的焦虑不是"流程不知道"（那种信息百度就能查），而是"我进了新群体，会不会是那个落下的"。

市面上已有的大学模拟器（Rubii 大学生活模拟器、乐辰大学、高校生活模拟器、JenoVa College Life、WorldOS、星野/猫箱等）全部落在同一格：**玩家扮演新生 + AI 生成内容**。这条路径已被填满，且该形态在 2025 年起下载量与投放双双腰斩，行业复盘的原因是同质化。

本项目走的是另一格：**先自我认知，再基于自我认知预演**。别人模拟世界，我们基于"你是什么人"模拟你自己。

## 四个维度（自建体系）

不是 MBTI 换名。第一、二维保留经典人格测量的内核，第三、四维是为"预演大学四年"专门设计的——大学最消耗一个大一新生的，恰恰是怎么对待截止日期，以及敢不敢同时试很多条路。

| 维度 | 两端 | 在量什么 |
|---|---|---|
| 一 · 你和自己的关系 | **H** 感受确认 / **A** 行动解决 | 先安放情绪，还是先解决事情 |
| 二 · 你和人的关系 | **C** 相伴充电 / **I** 独处充电 | 在人堆里恢复，还是一个人恢复 |
| 三 · 你和时间的关系 | **E** 提前铺好 / **D** 卡点爆发 | 提前量就是安全感，还是截止日期才是第一生产力 |
| 四 · 你和可能性的关系 | **P** 深耕一条 / **T** 广撒网试 | 认准一条走到底，还是试过才知道要什么 |

四个字母直接拼成类型代码（HCEP = 感受 · 相伴 · 提前 · 深耕），负责解释"你是怎么被算出来的"；每个类型另配一个有梗的传播名，负责让人一眼觉得"这也太像我了"。

## 功能流程

1. **UBTI 测验**：16 题，四个维度各 4 题，每题二选一。
2. **十六型角色卡**：代码 + 四词拼接 + 传播名 + 人设句 + 可爱之处 + 盲点提醒，以及四个维度各自的占比条。
3. **写下忐忑**：把对大学的期待/害怕写下来，它会成为预演的主线。
4. **七幕预演**：上课 / 破冰 / 恋爱 / 社交 / 社团 / 考试周 / 宿舍夜聊。每一幕由**三个维度字母共同分叉**，所以任意两种类型最多只有两幕读到相同文字——同一句焦虑，不同的人会读到完全不同的发展。
5. **引流问渠**：接入问渠「每日一问」，题库 14 道，遵循问渠的提问口径（特殊疑问句、≤50 字、完全自包含、禁止比喻文学化、禁止总结式提问），答完给一句追问——追问只挖"这件事碰到了你的什么"，不挖事件客观内容。
6. **二维码引流**：底部问渠 CTA + 二维码。当前问渠尚未上架，二维码为小红书 @鱼一朵，文案口径为「扫码关注小红书，上架后在这里说一声」。

## 技术栈

纯静态网页，**零构建**。原生 HTML + CSS + JavaScript（ES2020），无框架、无打包、无后端依赖。

- 人格计算：四维度加权投票（每维 4 题）
- 预演生成：本地叙事引擎（默认，离线可用）+ 可选 OpenAI 兼容接口
- 角色形象：16 张原创几何编辑风人物插画（PNG）。由开源 Skill `geometric-personality-studio` 生成——同一套视觉语法（约 4.5–5 头身、硬边多边形平面、小点眼、单一动作、单一象征物件、暖白背景 + 几何地面投影），只变身份、动作、物件与强调色，保证十六型在同一体系内互不相同。
- 存储：localStorage（仅用于保存用户自填的 API 配置，不上传任何数据）

选择零构建的理由：单人、短工时、需现场录屏，任何构建步骤失败都会直接影响交付；且本项目本质是前端逻辑，无需重框架。

## 七幕的分叉规则

每一幕都由三个维度共同决定，四个维度在七幕中分布均匀：

| 幕 | 参与的维度 |
|---|---|
| 上课 | H/A · C/I · P/T |
| 破冰 | C/I · E/D · P/T |
| 恋爱 | H/A · E/D · P/T |
| 社交 | C/I · E/D · P/T |
| 社团 | H/A · E/D · P/T |
| 考试周 | H/A · C/I · E/D |
| 宿舍夜聊 | H/A · C/I · E/D |

实测：全 16 型内部无整句重复，任意两型之间不存在"七幕里多数相同"的情况。

用户写下的那句忐忑只在**三幕**里被引用（破冰、宿舍夜聊固定锚定，第三幕按 H/A 分派到考试周或社交）。其余幕让位给类型自身携带的"怕"，避免同一句话在七幕里反复贴上、读起来发机械。

## 可选：接入真模型

默认使用本地叙事引擎，**无需联网、无需密钥，演示完整可用**。

若要让预演与追问由真模型生成：点页面右上角「配置 Key」，填入 OpenAI 兼容的 Base URL / API Key / Model（支持 OpenRouter 等中转），保存即可。留空则回落到本地引擎。

配置仅保存在浏览器 localStorage，代码中不含任何密钥。面板里有「清除」按钮可一键抹掉本地保存的密钥。

接口在 9 秒内没有响应，页面会自动回落到本地引擎（不会卡在转圈）；等待超过 4 秒时会露出一个"等太久？直接用本地引擎生成"的按钮，可以手动提前切回。

## 稳定性与边界处理

演示场景最怕的不是功能少，而是当场卡住或崩掉。这一版把下列情况都当作必须处理的情况写进了代码：

| 情况 | 处理 |
|---|---|
| 用户快速连点选项 | 170ms 过渡期内只接受第一次选择，不会跳题或串答案 |
| 接口配了 Key 但连不通 | 9 秒超时自动回落本地引擎；4 秒时露出手动跳过的入口 |
| 用户在焦虑框里输入 HTML/脚本 | 预演正文渲染前统一转义，标签只作为纯文本显示，不会被执行 |
| 某维度正好选成 2:2 | 该维标为"持平"并给出解释，不假装结果是确定的 |
| 焦虑只写了一句或写了上百字 | 超过 28 字自动截断显示，空值走另一套文案，两条路径都能出完整的七幕 |
| 手机窄屏（390px） | 标题、卡片、维度条、选项均单独调过，无横向溢出 |
| 想导出分享 | 「导出这张卡」调用浏览器打印，只输出当前这一屏，其余屏与按钮不参与排版 |
| 控制台干净度 | 无 JS 异常、无 404（含 favicon）、无失败请求 |

以上每条都有可复跑的浏览器端到端用例覆盖（无头 Chrome 驱动，含连点、注入、超时、边界输入、窄屏与打印版式）。

## 与问渠的关系

UBTI 脱胎于「问渠」App 的个人成长体系，但四个维度是重新设计的。问渠的提问口径沿用 `utils/prompts.ts` 的规则——不总结、不比喻、不追问事件本身，只问这件事碰到了你的什么。
